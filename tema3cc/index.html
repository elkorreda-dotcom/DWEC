Código ejecutado:

// ... (ver app.js para el resto)

Predicción y Resultados:

Variable / Expresión Valor TypeOf Espero TypeOf Sale

Nota sobre null: typeof null devuelve "object" debido a un error histórico de las primeras versiones de JavaScript que se ha mantenido por compatibilidad.

Ejercicio 3: Coerción y comparaciones

Evaluación de expresiones mixtas y comparaciones estrictas (===) frente a débiles (==).

Código ejecutado:

"5" - 2;
"5" + 2;
"10" * "2";
true + 1;
null + 5;
undefined + 1;
5 == '5'; 5 === '5';
0 == false; 0 === false;
null == undefined; null === undefined;

Tabla Expresión / Espero / Sale:

Expresión Espero Sale
"5" - 2 3 3
"5" + 2 "52" "52"
5 == '5' true true
5 === '5' false false
null == undefined true true
null === undefined false false

Explicación de la coerción: En las operaciones aritméticas (como -, *), JavaScript fuerza la conversión hacia número mandando el valor numérico. Sin embargo, en el operador +, si uno de los operandos es una cadena (string), manda la cadena y se realiza una concatenación de texto.
